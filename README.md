# Karczma Kuźnia

Website for a mountain inn restaurant. Menu with signature dishes, dish gallery, a hall for family events and table booking. Four languages: Polish, English, Czech, German.

![Preview](.github/preview.jpg)

**Live:** [karczma-kuznia.vercel.app](https://karczma-kuznia.vercel.app)

## Stack

HTML, CSS, JavaScript

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000.
